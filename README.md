# 线性代数电子教科书

按标准线性代数教材体系组织的中文电子教科书（Streamlit 呈现），内容只包含三件事：**知识点（含定理与完整证明）、解题方法（配完整例题）、习题（附完整解答）**。

**在线阅读**：https://linear-algebra-review-lab.streamlit.app/ — 点开即读，左侧选章（Streamlit Community Cloud 部署，代码更新到 main 后自动重新部署）。

## 内容结构

六章，与主流教材（如同济版）体系一致：

1. 行列式：定义与性质、按行（列）展开、范德蒙德行列式、克拉默法则
2. 矩阵及其运算：运算与警告、逆矩阵与伴随矩阵、矩阵分块法
3. 矩阵的初等变换与线性方程组：初等矩阵、矩阵的秩、方程组有解判定与解的个数
4. 向量组的线性相关性：线性组合与相关性、向量组的秩、向量空间、解的结构（基础解系）
5. 相似矩阵及二次型：内积与正交、特征值与特征向量、对角化、实对称矩阵谱定理、二次型与惯性定理、正定
6. 线性空间与线性变换：线性空间、基与坐标变换、线性变换及其矩阵、秩–零度定理

每章模板统一：知识点逐个编号细分，定理都给出证明（包括通常教材从略的转置行列式相等、按行展开定理、$|AB|=|A||B|$、谱定理、惯性定理等）；随后是解题方法一节，按题型分方法、给步骤与常见错误、配完整例题；章末 8 道习题，解答藏在可展开区域内，先做后看。全部数值例题与习题答案均经过程序精确验算。

## 本地运行

Python 3.10+，在仓库目录运行 `python -m pip install -r requirements.txt`，然后执行 `streamlit run app.py`。正文内容在 `textbook/` 包中，一章一个模块（`THEORY` 正文 + `EXERCISES` 习题与解答）。
